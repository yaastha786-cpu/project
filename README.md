Food Delivery Data Analysis Project

1. Project Overview

This project analyzes food delivery data to understand order trends, popular cities, cuisine preferences, delivery performance, and customer ratings.

2. Objectives

- Analyze orders across different cities.
- Identify popular cuisine types.
- Calculate average delivery time.
- Analyze order status.
- Understand customer ratings.

3. Tools and Technologies

- Python
- Pandas
- Matplotlib
- VS Code

4. Project Files

- "food_delivery_data_100_records.csv" – Original dataset
- "cleaned_food_delivery.csv" – Cleaned dataset
- "step1_check.py" – Dataset checking
- "step_clean.py" – Data cleaning
- "step3_eda.py" – Exploratory Data Analysis
- "step4_visualization.py" – Data visualization
- "step5_insights.py" – Business insights
- "visualizations/" – Graph images

The analysis provides an overview of food delivery order patterns, customer ratings, and delivery performance. These findings can help identify areas where delivery services may improve.
